# 🎙️ TechWave Podcast

**TechWave** is a modern and responsive podcast landing page designed for technology enthusiasts, young professionals, and anyone interested in technology, productivity, career growth, and personal development.

🌐 **Live Website:**
https://akkas07.github.io/Assignment-02-Start/

---

## 📌 About The Project

TechWave is a technology-focused podcast website where users can explore featured podcast episodes, learn about the show, discover its benefits, and get to know the host.

The website presents a clean and engaging interface with dedicated sections for podcast information, statistics, features, episodes, and the host.

## 🚀 Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/akkas07/Assignment-02-Start.git
```

### 2. Open the project folder

```bash
cd Assignment-02-Start
```

### 3. Run the project

Open `index.html` in your preferred web browser.

For development, you can use **Visual Studio Code** with the **Live Server** extension.
